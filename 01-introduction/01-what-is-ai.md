# What is an AI Engineer?

> AI Engineer adalah software engineer yang menggunakan teknologi Artificial Intelligence untuk membangun, mengintegrasikan, menguji, melakukan deployment, dan memelihara sistem AI yang menyelesaikan masalah nyata.

---

## 1. Overview

Artificial Intelligence (AI) berkembang dari sekadar penelitian menjadi bagian dari banyak produk dan layanan digital.

Contohnya:

- Chatbot
- Recommendation System
- Fraud Detection
- Image Recognition
- Speech Recognition
- Search Engine
- AI Coding Assistant
- Document Analysis
- Predictive Maintenance
- Price Prediction
- Generative AI
- AI Agent

Di balik sistem tersebut terdapat berbagai peran seperti:

- AI Engineer
- Machine Learning Engineer
- Data Scientist
- Data Engineer
- Software Engineer
- AI Researcher

Meskipun beberapa peran tersebut memiliki kemampuan yang sama, fokus dan tanggung jawabnya berbeda.

AI Engineer berada pada titik pertemuan antara:

```text
Software Engineering
        +
Artificial Intelligence
        +
Machine Learning
        +
Data
        +
Infrastructure
```

Tujuan akhirnya bukan hanya membuat model AI, tetapi membuat **AI system yang benar-benar dapat digunakan**.

---

# 2. What is an AI Engineer?

AI Engineer adalah seorang engineer yang bertanggung jawab untuk membangun sistem atau aplikasi yang memanfaatkan teknologi Artificial Intelligence.

Secara sederhana:

```text
Problem
   ↓
Data
   ↓
AI / ML Model
   ↓
Application
   ↓
Deployment
   ↓
Production
```

AI Engineer memastikan seluruh bagian tersebut dapat bekerja bersama.

Misalnya sebuah perusahaan ingin membuat sistem yang dapat membaca CV kandidat dan memberikan rekomendasi pekerjaan.

AI Engineer dapat mengerjakan:

```text
CV
 ↓
Document Processing
 ↓
Text Extraction
 ↓
Embedding
 ↓
AI Model / LLM
 ↓
Skill Analysis
 ↓
Job Matching
 ↓
API
 ↓
Web Application
```

Jadi pekerjaan AI Engineer tidak berhenti ketika model berhasil menghasilkan output.

Model tersebut harus dapat:

- digunakan oleh aplikasi
- menghasilkan output dengan benar
- memiliki latency yang dapat diterima
- aman
- dapat dimonitor
- dapat diperbaiki
- dapat menangani pengguna nyata

---

# 3. AI Engineer is More Than Building AI Models

Salah satu kesalahpahaman umum adalah:

> "AI Engineer adalah orang yang membuat model AI."

Pernyataan tersebut tidak sepenuhnya salah, tetapi terlalu sederhana.

Dalam praktiknya, AI Engineer dapat mengerjakan banyak hal di luar pembuatan model.

Contohnya:

```text
Data Collection
      ↓
Data Processing
      ↓
Model Selection
      ↓
Model Development
      ↓
Evaluation
      ↓
API / Integration
      ↓
Deployment
      ↓
Monitoring
      ↓
Optimization
```

Artinya AI Engineer perlu memahami **end-to-end AI system**.

# 4. AI Engineer vs AI Researcher

AI Engineer dan AI Researcher memiliki fokus yang berbeda.

## AI Researcher

Fokus utama:

```text
Research
   ↓
New Method
   ↓
New Algorithm
   ↓
New Architecture
   ↓
New Model
```

Contohnya:

- mengembangkan arsitektur neural network baru
- meningkatkan algoritma training
- mengembangkan metode baru untuk computer vision
- mengembangkan metode baru untuk NLP
- melakukan eksperimen penelitian

Output utamanya dapat berupa:

- research paper
- algorithm
- model architecture
- research prototype

---

## AI Engineer

Fokus utama:

```text
Existing Technology
       ↓
Engineering
       ↓
AI Application
       ↓
Production
```

Contohnya:

- menggunakan LLM API
- membangun RAG
- membuat AI Agent
- membuat inference API
- mengintegrasikan model ke aplikasi
- melakukan deployment
- mengoptimalkan latency
- mengontrol biaya inference
- melakukan monitoring

---

## Perbedaan sederhana

| AI Researcher           | AI Engineer                                  |
| ----------------------- | -------------------------------------------- |
| Meneliti teknologi baru | Menggunakan teknologi untuk membangun sistem |
| Fokus pada algoritma    | Fokus pada implementasi                      |
| Research-oriented       | Product-oriented                             |
| Eksperimen model        | Production system                            |
| Paper/model baru        | Application/system                           |

Namun dalam praktiknya, batas antara keduanya tidak selalu jelas.

AI Engineer tetap perlu memahami bagaimana model bekerja, sedangkan AI Researcher juga membutuhkan kemampuan programming dan engineering.

---

# 5. AI Engineer vs Machine Learning Engineer

AI Engineer dan Machine Learning Engineer memiliki banyak overlap.

Perbedaannya terutama terdapat pada fokus pekerjaan.

## Machine Learning Engineer

Machine Learning Engineer biasanya lebih fokus pada:

```text
Data
 ↓
Feature Engineering
 ↓
Training
 ↓
Evaluation
 ↓
Model
 ↓
Deployment
 ↓
Monitoring
```

Contohnya:

> Membuat model untuk memprediksi apakah transaksi merupakan fraud.

Model:

```text
XGBoost
Random Forest
Neural Network
```

---

## AI Engineer

AI Engineer memiliki cakupan yang dapat lebih luas, terutama pada aplikasi AI modern.

Contohnya:

```text
User
 ↓
Application
 ↓
AI System
 ├── LLM
 ├── RAG
 ├── Vector Database
 ├── Tools
 ├── API
 └── Business Logic
```

Contohnya:

> Membuat chatbot perusahaan yang dapat membaca dokumen internal dan menjawab pertanyaan karyawan.

---

## Perbandingan

| Aspek                | ML Engineer              | AI Engineer     |
| -------------------- | ------------------------ | --------------- |
| Machine Learning     | Sangat penting           | Penting         |
| Deep Learning        | Penting                  | Penting         |
| LLM                  | Opsional/tergantung role | Sangat relevan  |
| RAG                  | Tidak selalu             | Sangat relevan  |
| AI Agent             | Tidak selalu             | Relevan         |
| Model Training       | Sangat penting           | Tergantung role |
| Model Deployment     | Sangat penting           | Penting         |
| Backend/API          | Penting                  | Sangat penting  |
| Software Engineering | Penting                  | Sangat penting  |
| Product Integration  | Penting                  | Sangat penting  |

> Catatan: Nama posisi berbeda-beda antar perusahaan. Ada perusahaan yang menggunakan istilah "AI Engineer" untuk pekerjaan yang sebenarnya sangat dekat dengan ML Engineer.

# 6. AI Engineer vs Data Scientist

Data Scientist biasanya lebih fokus pada penggunaan data untuk menemukan insight dan membuat model analitik/prediktif.

Workflow sederhana:

```text
Business Problem
      ↓
Data
      ↓
Data Cleaning
      ↓
Exploratory Data Analysis
      ↓
Statistical Analysis
      ↓
Machine Learning
      ↓
Insight / Prediction
```

AI Engineer lebih fokus pada bagaimana teknologi AI tersebut menjadi sistem yang dapat digunakan.

```text
AI Model
   ↓
API
   ↓
Application
   ↓
Deployment
   ↓
Production
```

## Contoh

Perusahaan ingin memprediksi pelanggan yang akan berhenti menggunakan layanan.

### Data Scientist

Mungkin mengerjakan:

- analisis data pelanggan
- menemukan faktor churn
- membuat model prediksi
- mengevaluasi model
- memberikan insight kepada perusahaan

### AI Engineer

Jika model tersebut akan digunakan dalam aplikasi:

- membuat prediction API
- mengintegrasikan model dengan backend
- membuat inference pipeline
- deployment
- monitoring
- scaling

Contohnya:

```text

   ↓

   ↓

   ↓

   ↓

```

```text

   ↓

   ↓

   ├── ML Model
   ├── LLM
   ├── RAG
   ├── Vector Database
   └── AI Agent
   ↓
```

> **AI Engineering membutuhkan software engineering.**

Kemampuan seperti:

- Git

- deployment
- system design

tetap sangat penting.

# 8. Why Software Engineering Matters in AI

Model yang sangat bagus tidak otomatis menghasilkan aplikasi AI yang bagus.

Misalnya sebuah model memiliki akurasi sangat tinggi ketika diuji.

Namun ketika dimasukkan ke production:

```text
Model Accuracy = Excellent
       ↓
API = Slow
       ↓
Server = Overloaded
       ↓
Cost = Expensive
       ↓
User Experience = Bad
```

Sistem tersebut tetap gagal sebagai produk.

Karena itu AI Engineer perlu memperhatikan:

- performance
- latency
- scalability
- reliability
- security
- cost
- maintainability
- monitoring

# 17. Large Language Model (LLM)

LLM adalah model AI yang dilatih menggunakan data teks dalam jumlah besar dan dapat digunakan untuk berbagai tugas bahasa.

Contoh kemampuan:

- text generation
- summarization
- translation
- question answering
- classification
- coding
- information extraction

Sederhananya:

```text
User Prompt
     ↓
LLM
     ↓
Generated Response
```

Namun aplikasi LLM di production biasanya membutuhkan komponen tambahan.

---

# 18. Retrieval-Augmented Generation (RAG)

LLM memiliki keterbatasan ketika membutuhkan informasi khusus yang tidak terdapat dalam konteksnya.

RAG memungkinkan sistem mengambil informasi dari sumber eksternal sebelum menghasilkan jawaban.

```text
User Question
      ↓
Retriever
      ↓
Relevant Documents
      ↓
LLM
      ↓
Answer
```

Contoh:

> Membuat chatbot yang dapat menjawab berdasarkan dokumen perusahaan.

Pipeline:

```text
PDF
 ↓
Text Extraction
 ↓
Chunking
 ↓
Embedding
 ↓
Vector Database
 ↓
Retrieval
 ↓
LLM
 ↓
Answer
```

RAG merupakan salah satu kemampuan penting dalam AI Engineering modern.

# 35. Key Takeaways

1. AI Engineer adalah engineer yang membangun sistem yang memanfaatkan Artificial Intelligence.

2. AI Engineer tidak selalu harus membuat model AI dari nol.

3. AI Engineer dapat menggunakan existing models seperti LLM dan mengintegrasikannya ke aplikasi.

4. Software Engineering merupakan fondasi penting untuk AI Engineering.

5. Machine Learning Engineer lebih berfokus pada lifecycle model ML, sedangkan AI Engineer dapat memiliki cakupan lebih luas pada AI application.

6. AI Engineer perlu memahami data, model, API, application, deployment, dan monitoring.

7. AI Engineering modern mencakup:
   - Machine Learning
